# InkScribe Editor

InkScribe is a premium, highly interactive rich-text editor built for the web. It features a stunning glassmorphic UI, dynamic block-based editing, and seamless cross-mode synchronization. Built on React and Vite, InkScribe allows users to craft, review, and preview content effortlessly.

## Features
- ✍️ **Block-Based Editing**: Seamlessly add paragraphs, headings, blockquotes, code blocks, tables, and media.
- 🎨 **Direct Style Swapping**: Instantly convert blocks (e.g., from `H1` to `H2`, or `Info` to `Danger` callouts) while preserving styling.
- 💬 **Interactive Review Mode**: Allows editors to leave, resolve, and manage comments directly attached to specific blocks of text.
- 🌗 **Premium Theming**: Supports both a sleek Dark Mode (glassmorphism) and a clean Cream Mode.
- ⚡ **Instant Syncing**: Changes in the draft immediately reflect across all tabs and modes without latency.
- 📦 **Inkpack Engine**: Rock-solid, completely offline architecture.

## Quick Start

1. Clone or download the repository.
2. Ensure you have [Node.js](https://nodejs.org/) installed.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```

## Build for Production
To generate a minified, production-ready bundle (output to the `dist` folder):
```bash
npm run build
```
